# OOC Makers

캐릭터 롤플레이 대화에 붙여 쓰는 OOC 프롬프트와, 그 출력을 보기 좋게 바꿔 주는 도구 모음입니다.
모두 한 장짜리 HTML이라, 내려받아 브라우저에서 바로 열어도 동작합니다.

**https://bitcuit.github.io/OOC_makers/**

## 도구

| 도구 | 하는 일 |
|---|---|
| [CHARACTER FILE](Character_File/index.html) | 캐릭터 소개와 스킬을 보여 줍니다. 선택 판정 상세, 이미지와 글꼴을 고르는 가로 배너, 기준색 자동 변형을 지원하고 PNG · 반응형 HTML로 저장합니다 |
| [FOOD TOP3](Food_TOP3/index.html) | 캐릭터마다 좋아하는 음식 · 음료 · 과일 · 과자 TOP3를 뽑는 OOC. 챗봇 출력을 붙여넣으면 캐릭터별 4칸 도시락 카드로 보여 주고, PNG · HTML로 저장합니다 |
| [FOODIE GUIDE](Foodie_Guide/index.html) | 캐릭터마다 자주 가는 맛집을 뽑는 OOC. 챗봇 출력을 붙여넣으면 캐릭터별로 영수증(늘 시키는 메뉴 · 가격 · 합계)과 메모 한 장(시그니처 · 맛 묘사 · 별점 · 한줄평)을 나란히 보여 주고, PNG · HTML로 저장합니다 |

## 쓰는 순서

1. 도구에서 **OOC 복사**를 눌러, 캐릭터를 아는 대화에 붙여넣습니다.
2. 챗봇이 정해진 양식으로 답하면, 그 답을 통째로 복사해 도구의 **챗봇 출력 붙여넣기** 칸에 넣습니다.
3. 바로 카드가 그려집니다. 붙여넣은 내용은 그 브라우저에 남아 다시 열어도 그대로입니다.

## GitHub Pages

Settings → Pages에서 Source를 `main` 브랜치 + `/ (root)`로 지정하면 배포됩니다.
루트 [`index.html`](index.html)이 도구 목록이고, 각 도구는 폴더 주소로도 바로 열립니다.
